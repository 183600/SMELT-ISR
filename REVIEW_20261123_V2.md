## Detailed Findings

### t-Distribution Critical Values ✅
- **`_t_critical` function** (`part_025_statistics.py`): Uses bisection root-finding on the two-sided p-value function. Verified correctness of special cases:
  - **df=1 (Cauchy)**: `cot(π·α/2)` — correct (matches t_{0.975,1} = 12.706)
  - **df=2**: `(1-α) × √(2/(α(2-α)))` — **verified correct** against numerical solution and known table values (t_{0.975,2} = 4.303, t_{0.995,2} = 9.925)
  - **df > 2**: Bisection with exponential upper-bound search, 200 iterations, convergence check
- **`_meta_t_critical_975`** (`part_050_meta.py`): Independent bisection implementation for meta-analysis, also verified correct.

### Meta-Analysis ✅
- **DerSimonian-Laird random effects** (`part_050_meta.py`): Correctly uses t-distribution (df=k-1) for CI and p-values in random-effects summary, citing Hartung & Knapp (2001) and IntHout et al. (2014). Fixed-effect uses z (standard for fixed-effect model).
- **Heterogeneity**: Q, I², H², τ² all properly computed. Prediction interval uses t-distribution.
- **Chi-square survival**: Correctly implemented via regularized upper incomplete gamma function.

### Equivalence Testing ✅
