## Bug Fixes Summary

### Bug 1: `exp/part_029_ablation.py:487`
**Issue**: `if sd_observed is not None and effect_value != 0.0:` incorrectly checked `effect_value` instead of `baseline_abs` to determine the statistical design (welch vs paired). This would never properly trigger the design selection block when it should.

**Fix**: Changed to `if sd_observed is not None and baseline_abs != 0.0:` to match the correct pattern used in `exp/part_025_statistics.py:110`. The design determination should depend on whether a baseline absolute value exists, not whether the effect value is non-zero.

### Bug 2: `exp/part_026_equivalence.py:837`
**Issue**: `if sd_observed is not None and delta_value != 0.0:` incorrectly checked `delta_value` instead of `baseline_abs` to determine the statistical design (welch vs paired). Same class of bug as Bug 1.

**Fix**: Changed to `if sd_observed is not None and baseline_abs != 0.0:` to correctly use the baseline absolute value for design selection.

Both fixes align with the established pattern in `exp/part_025_statistics.py:110` where `bl_abs != 0.0` is the correct condition for determining welch vs paired design.
