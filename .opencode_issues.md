# Temporary data-methodology issue list (not a report)

Prioritized, leakage-first. Delete before finishing.

1. [P0] Cross-split leakage is warning-only by default: sampled duplicate
   windows / exact duplicate groups only abort training when
   `--strict-data-audit` is passed. Make leakage-class findings a default
   hard gate (with an explicit opt-out recorded in the run protocol).
2. [P0] Train decontamination only exists for exact duplicate groups and is
   opt-in. Add exact window-level decontamination of train against val/test
   (works without group separators; masks every train window that matches an
   eval window), and make statistical baselines use the same effective data.
3. [P1] Distribution-shift audit only compares unigram byte histograms. Add
   token-transition (bigram) JS shift and train-internal temporal drift
   (first half vs second half), so future-shift / non-stationarity is visible
   before training.
4. [P1] Outlier checks are limited to the most frequent byte. Add split-level
   byte entropy, duplicate-window ratio, and (for grouped corpora) robust
   group-length outlier checks fitted on train only.
5. [P2] Audit does not explicitly check NaN/Inf for future non-byte feature
   pipelines, nor duplicate labels/rows at the tensor level. Add finite-value
   checks without changing the byte pipeline.
6. [P2] Resume accepts changed data silently (warning only). A data hash change
   invalidates the split trajectory and any test-seal provenance; consider
   refusing resume on changed data.
